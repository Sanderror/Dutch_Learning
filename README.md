# Tegeltjes: Dutch from Spanish

A private Duolingo-style app for learning Dutch from (Venezuelan) Spanish. One lesson a day; every finished lesson paints a tile.

**App:** https://sanderror.github.io/Dutch_Learning/ (open in Chrome on Android and tap "Instalar la app"; Chrome's menu, "Add to Home screen", does the same)

**Course so far:** units 1 to 10, all of section 1 (A0): 60 lessons, 805 sentences, 313 words, 10 dialogues.

| Folder | What it is |
|---|---|
| `app/` | The app: plain HTML, CSS and JavaScript modules. No build step, no dependencies |
| `content/` | The course as data: `course.json` (index), `lexicon.json`, `units/uNN.json`, plus `curriculum_alignment.md` |
| `audio/` | Recordings, generated by a workflow. Do not edit by hand |
| `tools/` | Content validator, review-batch builder, audio build, and their tests |
| `review/` | Review process, review logs and checker flags |
| `spike-a-speech/`, `bakeoff/` | Phase 0 tests: speech recognition and the voice comparison |

## How a unit gets from idea to her phone

1. Write `content/units/uNN.json` and add its words to `content/lexicon.json`; list the unit in `content/course.json`.
2. `python3 tools/validate_content.py content` must report 0 errors.
3. An independent checker reviews it against `tools/review_rubric.md`; then `tools/make_review_batch.py` builds the short list Sander reviews (`review/review_process.md`).
4. Merge to `main`. The "Build audio" workflow synthesises recordings for the new Dutch text and GitHub Pages publishes everything. The app picks it up the next time it is opened online.

## The app

- `app/js/checker.js`: answer checking. Accents and spacing are forgiven, typos on long words too, unless the typo is another Dutch word or touches a Spanish ending.
- `app/js/exercises.js`: turns a lesson's sentences into steps. One exercise per sentence, a word card before each new word's first use, one matching game. Seeded, so reproducible.
- `app/js/store.js`: progress in the phone's local storage, with export and import.
- `app/js/main.js`: the interface. `app/sw.js` makes it installable and usable offline.
- A unit is eight tiles: six lessons, a dialogue, and a test-out (12 questions, 10 right completes the unit).
- Until recordings exist for a text, the phone's own Dutch voice reads it.
- When Chrome reports the app can be installed, the home screen and the settings show an install button.

## Tests

```
python3 tools/validate_content.py content      # content rules; exit code 1 on errors
python3 tools/test_validator.py                # 27 injected mistakes, each must be caught
python3 tools/test_review_batch.py             # review-batch selection
python3 tools/test_build_audio.py              # audio build against a mock API
python3 tools/test_tts_bakeoff.py              # voice script against a mock API
node tools/test_scoring.mjs                    # speech-test scoring, incl. the real Pixel runs
node --test app/tests/*.test.mjs               # app logic: checker, exercises, store (26 tests)
```

End to end in a real Chrome at phone size (needs Chrome and `puppeteer-core`):

```
python3 -m http.server 8765                    # in the repository root
node app/tests/e2e.browser.mjs screenshots/    # plays every lesson, a dialogue, a test-out; install; offline; reload
```

Python 3.9+ and Node 20+. Nothing to install for the first block.

## Content format in short

- `lexicon.json` lists every Dutch form taught and the lesson where it first appears (`"forms": {"ben": "u01l1", "bent": "u01l2"}`). It is the single source for "what has she been taught so far". `accept_es` / `accept_nl` are extra answers accepted on the word card only.
- A unit holds lessons; a lesson holds sentences with Dutch (`nl`), Spanish (`es`) and other accepted answers (`alt_nl`, `alt_es`); plus a grammar note in Spanish and a dialogue with questions.
- `names` in the lexicon are people and places that may appear without being taught.
- A Dutch word with two unrelated uses is two entries with the same `nl` (het as pronoun and as article; zij as ella and as ellos; zijn as verb and as possessive). The number one is written `één` so it stays apart from the article `een`; answers without accents are accepted.

| Validator check | Rule |
|---|---|
| gate | every Dutch word in a sentence is a form taught in that lesson or earlier |
| load | at most 6 new words per lesson; each used in at least 2 sentences of that lesson |
| length | at most 8 words per sentence in section 1, rising to 12 by section 5 |
| articles | de/het before a noun matches the lexicon; noun glosses carry el/la |
| spanish | opening ¿ and ¡ present; no vosotros forms |
| duplicates | no Dutch sentence is taught twice as new |
| course | `course.json` lists exactly the unit files; every dialogue speaker has a voice |
| recurrence | warning when a word has appeared in fewer than 3 sentences so far |
